# Return or exchange: which one do I need?

Last updated: 2026-10-30

Both options are available only after your order has been **delivered**.

| | Return | Exchange |
| --- | --- | --- |
| What you get | A refund | The same product in a different option (for example, another size or color) |
| Where the money goes | Your original payment method or an existing gift card | You pay or receive any price difference |
| Order status after you confirm | Return requested | Exchange requested |
| Next step | We email you return instructions | We email you instructions for sending the original items back |

An exchange can't change the product type.
